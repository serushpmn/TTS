# Dialogue Studio — Feature Roadmap

موارد زیر به‌صورت مرحله‌ای به پروژه اضافه می‌شوند. وضعیت هر مورد را هنگام شروع کار در این فایل و در todo جلسه به‌روز کنید.

---

## مرحله ۱ — کنترل مکث و فاصله

| ID | مورد | جزئیات | وضعیت |
|----|------|--------|--------|
| `pause-presets` | مکث‌های آماده | دکمه‌های کوتاه / معمولی / طولانی؛ مکث بین خطوط و تعویض گوینده باید per-project قابل تنظیم باشد، نه یک الگوی ثابت برای همه مکالمات | **done** |
| `trim-silence` | حذف سکوت اضافی | بریدن سکوت ابتدا و انتهای هر قطعه قبل از چسباندن، در صورت نیاز (قابل روشن/خاموش) | **done** |

---

## مرحله ۲ — پیش‌نمایش و مدیریت صداها

| ID | مورد | جزئیات | وضعیت |
|----|------|--------|--------|
| `voice-preview-samples` | نمونه صوتی ازپیش‌ساخته | برای هر صدا دکمه پخش نمونه؛ فایل‌ها از قبل تولید و ذخیره شوند تا هر بار مدل اجرا نشود | **done** (bake via UI or script) |
| `voice-avatars` | تصویر گوینده | آواتار/عکس برای male و female (و در صورت امکان per-voice) | **done** (SVG) |
| `voice-filters` | دسته‌بندی | فیلتر بر اساس زبان، جنس صدا، لهجه | **done** |
| `voice-compare` | مقایسه صدا | شنیدن و مقایسه همزمان ۲ یا ۳ صدا | **done** |
| `voice-favorites` | علاقه‌مندی‌ها | ذخیره صدای موردعلاقه | **done** |
| `voice-default` | صدای پیش‌فرض | انتخاب صدای پیش‌فرض برای پروژه‌های بعدی (در prefs) | **done** |

**نکته:** به‌جای نمایش صرف `af_heart` / `am_michael`، نام خوانا + نمونه + آواتار.

## مرحله ۳ — تلفظ و بیان

| ID | مورد | جزئیات | وضعیت |
|----|------|--------|--------|
| `pronunciation` | واژه‌نامه تلفظ | دیکشنری محلی برای نام‌ها، اختصارات و واژه‌های دشوار (قبل از سنتز اعمال شود) | **done** |
| `emotion-tags` | لحن و احساسات | برچسب‌های قابل انتخاب در UI برای لحن/احساس، نه فقط تایپ تگ در متن | **done** (speed/pause approximations; not native emotion) |

**محدودیت Kokoro:** احساسات واقعی مدل‌محور ممکن است محدود باشد؛ هر برچسب باید به قابلیت واقعی (سرعت، مکث، تقریب آوایی، یا پردازش صدا) نگاشت شود و ادعاهای غیرواقعی نکند.

## مرحله ۴ — زبان سنتز و UI

| ID | مورد | جزئیات | وضعیت |
|----|------|--------|--------|
| `synth-lang` | زبان تولید صدا | انتخاب زبان سنتز (مثلاً آلمانی) وقتی صدا/مدل پشتیبانی می‌کند | **done** (de/es/fr/it experimental via Torch+espeak; ONNX English-only) |
| `ui-i18n` | چندزبانه کردن سایت | رابط کاربری به فارسی، انگلیسی، آلمانی | **done** (EN / FA / DE, RTL for FA) |

## مرحله ۵ — اصطکاک روزمره (اولویت بالا)

| ID | مورد | جزئیات | وضعیت |
|----|------|--------|--------|
| `optional-gender-mix` | قانون زن+مرد اختیاری | اجبار ترکیب female/male برای پادکست دو نفره خوب است، ولی برای Lecture تک‌نفره یا دو گوینده هم‌جنس مزاحم است. حداقل در Lecture یا با سوئیچ prefs مثل `strict_cast` اختیاری شود | **done** (`strict_cast` prefs + UI checkbox; default on) |
| `preview-with-delivery` | پیش‌نمایش با لحن و زبان | Preview باید همان Tone + Speech language انتخاب‌شده را اعمال کند، نه فقط voice خام | **done** |
| `engine-lang-guard` | هشدار ناسازگاری مدل/زبان | قبل از Generate، اگر مثلاً آلمانی + ONNX انتخاب شده، پیام واضح بدهد (Torch لازم است) نه شکست بعد از شروع | **done** (UI warn + API reject on preview/generate/lecture/regen) |
| `export-ux` | Export راحت‌تر | کپی مسیر فایل؛ نام‌گذاری خودکار از Topic + تاریخ؛ وضوح بیشتر کنار WAV/MP3 | **done** (download name Topic+date; Copy path / Copy URL) |

## مرحله ۶ — کیفیت صدا و جریان کار

| ID | مورد | جزئیات | وضعیت |
|----|------|--------|--------|
| `tone-samples` | نمونه کوتاه هر لحن | یک کلیپ کوتاه از پیش‌ساخته یا on-demand تا کاربر قبل از Generate فرق Calm / Excited را بشنود | pending |
| `smart-line-regen` | ویرایش بعد از Generate | عوض کردن یک خط و بازتولید/چسباندن همان بخش بدون حس «کل پروژه از نو»؛ UX واضح‌تر روی ↻ موجود | pending |
| `project-profiles` | پروفایل پروژه | دکمه‌هایی مثل Podcast / Lecture / Story که pause + trim + tone پیش‌فرض را یک‌جا ست کنند | pending |
| `smarter-import` | Import بهتر | پشتیبانی از جدول ساده، SRT، یا چسباندن از چت‌بات با تشخیص خودکار نام گوینده | pending |

7. i18n رابط کاربری (پایه)
